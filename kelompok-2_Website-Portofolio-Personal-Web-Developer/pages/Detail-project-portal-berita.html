Portal Berita Teknologi/Mading Sekolah

Website untuk menyampaikan berita teknologi, informasi sekolah, dan kegiatan siswa.

Tentang Project

Website ini dirancang sebagai media informasi digital untuk siswa dan warga sekolah. Berita dan pengumuman dapat disusun dalam halaman yang rapi sehingga mudah dibaca.

Fitur Project

  • Daftar berita terbaru.
  • Kategori berita teknologi dan sekolah.
  • Gambar dan ringkasan berita.
  • Halaman untuk membaca berita.
  • Informasi kegiatan dan pengumuman sekolah.

Proses Pembuatan

Halaman berita disusun menggunakan HTML. CSS digunakan untuk mengatur tata letak artikel, ukuran gambar, tipografi, dan tampilan responsif.
