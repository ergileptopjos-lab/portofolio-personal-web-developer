Katalog Toko Online

Website katalog untuk menampilkan berbagai produk beserta harga dan informasi produk.

Tentang Project

Website ini dibuat untuk membantu pengunjung melihat produk yang tersedia tanpa harus datang langsung ke toko. Tampilan dibuat sederhana agar produk mudah ditemukan.

Fitur Project

  • Menampilkan daftar produk.
  • Informasi nama dan harga produk.
  • Gambar untuk setiap produk.
  • Kategori produk.
  • Tampilan responsif untuk HP dan komputer.

Proses Pembuatan

Halaman dibuat menggunakan HTML untuk struktur konten dan CSS untuk mengatur tampilan produk, jarak, warna, serta tata letak.
