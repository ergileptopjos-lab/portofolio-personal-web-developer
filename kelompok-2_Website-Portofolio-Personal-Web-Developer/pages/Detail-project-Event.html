Event dan Pendaftaran Workshop

Website informasi kegiatan dan pendaftaran workshop untuk siswa maupun peserta umum.

Tentang Project

Project ini dibuat untuk menampilkan informasi acara dalam satu halaman. Pengunjung dapat melihat jadwal, lokasi, dan persyaratan sebelum mendaftar.

Fitur Project

  • Informasi nama dan deskripsi acara.
  • Jadwal serta lokasi workshop.
  • Persyaratan peserta.
  • Formulir pendaftaran peserta.
  • Informasi kontak penyelenggara.

Proses Pembuatan

HTML digunakan untuk menyusun informasi acara dan formulir. CSS digunakan untuk membuat tampilan halaman lebih rapi dan nyaman digunakan.
